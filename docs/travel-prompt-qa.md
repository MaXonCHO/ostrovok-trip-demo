# Проверка поиска по пожеланиям

27 октября 2026 года. Проверен текущий вариант: однострочный `input#trip-request` и встроенные фильтры, которые заменяют форму пожеланий. Кнопки «Применить фильтры» и прежнего модального окна фильтров больше нет. Изменения сохраняются автоматически; «К пожеланиям» возвращает ввод с сохранённым текстом.

Проверены **7 targeted-сценариев** из `tests/e2e/travel-prompt.spec.ts`. Все прошли. После последнего удаления кнопки Apply повторены только два затронутых сценария; они также прошли. TypeScript — без ошибок.

| Сценарий | Проверенный результат |
| --- | --- |
| Текстовый подбор | «Хочу в Казань с бассейном до 8 тыс» передаёт `city=kazan`, `amenities=Бассейн`, `maxPrice=8000` и исходный `wish`; поле `q` не используется для пожелания |
| Встроенные фильтры | Город, даты, взрослые, дети и номера сохраняются после «К пожеланиям» и повторного открытия; фокус возвращается вводу. «Найти» внутри фильтров учитывает явно выбранный город, даже если в пожелании указан другой |
| Голосовой ввод | Mock SpeechRecognition не создаётся и не стартует до нажатия. После нажатия используется `ru-RU`; результат добавляется к тексту. Stop возвращает редактирование, отказ в доступе показывает сообщение и сохраняет возможность продолжить текстом |
| Отсутствие SpeechRecognition | Отображается понятное сообщение, текстовый ввод остаётся доступен; реальный аудиозахват не запрашивается |
| Первый экран и финальный CTA | На 1440×900, 390×844 и 320×568 hero не выше viewport; заголовок, input, «Фильтры» и «Подобрать» видны. Горизонтального переполнения нет. «Начать мою поездку» возвращает prompt и фокусирует input, в том числе из режима фильтров |
| Панели на 320 px | Город, календарь и гости открываются внутри встроенной формы; не выходят за левый/правый край. Все действия «Готово» доступны обычным кликом. Возврат «К пожеланиям» работает |
| Колесо над hero | Во всех 6 сочетаниях трёх viewport × prompt/filters движение колеса на 600 px изменило `window.scrollY` с 0 ровно до 600. Body не заблокирован, `overflow-y` body и hero-content равен `visible` |
