# Проверки прототипа

Историческая проверка до редизайна. Текущий интерфейс и каталог проверены отдельно, см. [verification-redesign.md](verification-redesign.md).

Дата: 27 октября 2026. Mac ARM64, Node 22.14.0, Next 16.4.3, production standalone на 8080. Каталог и внешние провайдеры демонстрационные. Никакие результаты ниже не подтверждают качество настоящего геосервиса или автономного агента.

## Выполнено

- `npm run build`: production-сборка завершена, маршруты и API скомпилированы.
- `npm run typecheck`: TypeScript strict, без ошибок.
- `npm run lint`: без ошибок и предупреждений.
- `npm test`: 19 доменных/сервисных проверок, включая единообразие городов, обязательные интересы и вместимость, бюджет за проживание, конкурентную запись, идемпотентность, приватность, изменение цены после предложения и сохранение обязательности пожелания.
- Playwright: 12 сквозных проверок прошли в production runtime. Полный итог записан после завершающего прогона в `verification/e2e-results.txt`.
- Проверены одиночный путь, два независимых cookie-контекста, приглашение, конкурирующие голоса с 409 и повтором, одноголосное veto, отдельное финальное подтверждение, неизвестное направление, отсутствие предпочтений, конфликт сценариев и его разрешение автором, вопрос отельеру и извлечение, геоистория, отозванная ссылка, три участника, поздний viewer и переоткрытие, все отклонённые сценарии, неизвестная цена, выход и запрет подмены демо-персоны.
- JSON/Node persistence: отдельный standalone-сервер дважды запущен с одним временным каталогом; сохранились HttpOnly-сессия, версия поездки и голос. Отчёт `verification/persistence-results.json`.
- `npm audit`: известных уязвимостей в установленном дереве нет. Для esbuild зафиксирован исправленный override 0.28.2.

## Визуал и доступность

90 сочетаний: 9 основных экранов × 5 ширин × 2 темы. Ширины 360, 390, 768, 1024, 1440 CSS px. Проверены отсутствие горизонтальной прокрутки и битых изображений. Axe WCAG 2 A/AA и 2.1 AA выполнялся на 390 и 1440 для каждой темы. В финальном прогоне: 0 обнаруженных нарушений Axe, 0 overflow, 0 битых изображений, 0 pageerror. Это автоматическая проверка, не сертификат доступности.

Скриншоты: `verification/screenshots/`, JSON-результаты: `verification/visual-results.json`. Вручную просмотрены главная, сценарии, карточка и подробности отеля в мобильной и desktop-композиции, включая тёмную тему. Дополнительно проверены горизонтальный жест по фотографии, отмена, отсутствие голоса при вертикальном движении, Escape и возврат фокуса. При этой проверке обнаружено и исправлено стандартное браузерное перетаскивание изображений, которое перехватывало свайп. Проверка нашла и исправила разрыв логотипа на телефоне, слишком широкое правило SVG в схеме и ARIA-роли звёздности. Контекст поездки на телефоне раскрывается, участники доступны отдельным раскрытием. Reduced motion включён и проверен в браузере; жесты дублируются кнопками. Модальные окна используют Radix, поддерживают Escape и возврат фокуса.

## Производительность

`verification/performance-results.json`: один локальный лабораторный переход на главную, Chromium headless, 1440×900, без замедления сети/CPU. LCP около 72 мс, CLS 0 в этом запуске. Эти цифры описывают только локальное окружение и не подтверждают показатели на телефоне через интернет. INP и полевые Core Web Vitals не измерялись.

## Что не проверено или не подключено

- Docker/Compose и архитектура linux/amd64: на Mac нет Docker. Контейнерные файлы подготовлены по техничке; базовый тег проверен на наличие amd64 и arm64. Проверка Node standalone не заменяет Docker build/run и проверку volume.
- Реальное вычисление по геоданным и настоящая автономная агентная логика: адаптеры/контракты подготовлены, в этом прототипе работают fixture/mock.
- Настоящие цены, доступность и качество объектов: синтетические.
- Видео гостей: не предоставлено, показано честное отсутствие.
- Публикация, репозиторий организации, общедоступный скринкаст, тег submission: не выполнялись, требуют действий пользователя перед сдачей.

## Повторить

```sh
npm run build
npm start
# Отдельный терминал:
E2E_SERVER=1 npm run test:e2e
node scripts/visual-check.mjs
node scripts/persistence-check.mjs
node scripts/performance-check.mjs
```

Для browser-проверок предварительно `npx playwright install chromium`. Приложению эта установка не нужна. Проверки создают отдельные браузерные сессии и личные демо-сцены, не сбрасывают пользовательские поездки.
