# Аудит типографики

Дата: 27 октября 2026 года. Проверен локальный интерфейс Островка: главная `/`, выдача `/search?city=sochi`, отель `/hotel/pullman-sochi-centre`, открытые поисковые панели, фильтры и диалоги. Ширины Chromium: **1440, 390 и 320 px**.

## Источники и подлинность шрифтов

Брендбук `Брендбук Островка/шрифты/о-шрифтах.txt` определяет Spoof Medium для фирменной типографики и Nagel как основу доработанного логотипа. Логотип используется оригинальным SVG, а не набран текстом Nagel. Голос/Golos остаётся в прежнем агентном интерфейсе; новые экраны используют PT Root UI и Spoof.

Современная главная Островка была получена с обычным Chrome User-Agent. Использованы её реальные таблицы стилей, а не размеры, оценённые по картинке:

- [Глобальный CSS и объявления шрифтов](https://mpf.fastrovok.net/branch/b173060/_next/static/css/d561bc272b62b8dd.css).
- [Компоненты главной и responsive-правила](https://mpf.fastrovok.net/branch/b173060/_next/static/css/8322ce622b294922.css).
- Локальная HTML-копия для исследования: `/private/tmp/ostrovok-desktop-reference.html`.

Имена файлов и хеши WOFF2 в текущем CSS совпадают с сохранёнными в `public/ostrovok`. Независимо проверены бинарные таблицы `name`, `OS/2` и `cmap`: **PT Root UI Web Regular 400, Medium 500, Bold 700; Spoof Medium 500**, все файлы статические, а не variable fonts. Результат: [typography-fonts.json](typography-fonts.json).

Проверена вся русская азбука в обоих регистрах, включая Ё/ё: глифы есть во всех четырёх файлах. В Spoof нет знака ₽, поэтому цены явно используют PT Root UI, где этот глиф есть. В браузере все четыре применяемых начертания имели статус `loaded`; у Spoof подтверждено `FontFace.featureSettings = "ss06"`, как в оригинале. Таким образом, кириллица интерфейса не зависит от подмены системным шрифтом.

В CSS оригинала часть весов записана как `480` для PT или `400` для Spoof. При единственных доступных статических лицах это выбирает PT Medium 500 и Spoof Medium 500. В проекте указаны реальные веса 500; искусственное утолщение отключено после проверки отдельных Regular/Medium/Bold.

## Проверка

Команда: `E2E_SERVER=1 npx playwright test tests/e2e/typography.spec.ts --reporter=list`.

**6 из 6 targeted-тестов прошли**. Проверено:

- 9 рендеров: три экрана × 1440 / 390 / 320 px. Нет горизонтального переполнения документа, непредусмотренно обрезанных заголовков/цен и осмысленного текста менее 12 px.
- 14 раскрытых панелей: город, даты, гости и выбор номера на трёх ширинах; фильтры на двух мобильных ширинах. Ширина панелей не выходит за экран, редактируемые поля на телефоне ≥16 px.
- Все три выпадающие панели на главной при каждой ширине дополнительно проверены на обрезание предками полноэкранного hero.
- Полное название статьи открывается без обрезания на трёх ширинах; ссылка ведёт на оригинальную статью.
- Фиксированная фотография сезонного раздела сохраняет положение при прокрутке, белые соседние разделы ограничивают окно через clip; фон покрывает видимую область без пустых полос. При `prefers-reduced-motion: reduce` используется обычный абсолютный фон.
- На ПК увеличение фото еды и осеннего отеля превышает 1.05 при неизменных границах рамки. На touch и при reduced-motion масштаб равен 1.
- Отдельно проверено соотношение H1/H2 при пустой выдаче.
- TypeScript проверен без ошибок.

Результаты и текущие скриншоты находятся в `test-results/typography-after.json`, `typography-panels.json`, `typography-fixed-window.json`, `typography-hover.json`; изображения — `typography-after-{home,search,hotel}-{1440,390,320}.png`, `typography-halloween-{1440,390,320}.png`, `typography-blog-expanded-{1440,390,320}.png`.

**Not verified:** пиксельное равенство оригинальному мобильному рендеру; собственного мобильного скриншота оригинала нет, проверены его CSS media queries и локальный рендер. Нативный iOS Safari и пользовательские настройки шрифтов ОС не запускались. Контраст и полный функциональный регрессионный прогон не являются предметом этого повторного типографического аудита. Последнее изменение позиции/цвета шапки проверяется владельцем задачи отдельно; размеры текста шапки не менялись.

Approve — для проверенных локальных экранов и состояний на 1440, 390 и 320 px.
