# Новый дизайн, уточнения пользователя

Светлая версия по умолчанию. Главная теперь лендинг с быстрым началом поездки. Сценарии и отели выбираются последовательно: одна крупная фотокарточка, стек следующей карточки, жест влево/вправо, короткая подпись направления и компактные доступные управляющие элементы. Общие голоса и подтверждение сохраняют прежнюю семантику.

Визуальная основа: шесть вложений пользователя в docs/references, особенно большие фотографии и карточные интерфейсы Travel / Isola Bella, Smart Travel Hotel и Nature Power. Desktop получает широкую фотосцену, мобильная версия компактную вертикальную колоду. Технические пояснения уходят из основного поля выбора в раскрываемый контекст.

Дополнительные просмотренные источники:
- https://vibecoding.ru/build/ui-components: выбран Motion Primitives для сдержанного появления разделов, существующий Motion для жестов, Radix для диалогов.
- https://motionsites.ai: композиции hero travel Aetheris Voyage и крупные фотографические сцены, без копирования платных ресурсов.
- https://21st.dev: фотографические hero и card-stack интерфейсы как визуальная основа. Сторонние шаблоны и рекламные показатели не копируются.
- Reveal адаптирован из открытого InView Motion Primitives (MIT), исходник и лицензия указаны в компоненте и отдельном файле.

Каталог переводится на реальные отели с фотографиями их официальных сайтов. Цена, маршрут и условия подбора остаются демо и подписываются отдельно. Выдуманные отзывы не приписываются реальным объектам.
