# Что понадобится утром

Прототип открывается на http://localhost:8080. Готовые сцены: http://localhost:8080/demo. Если процесс остановлен, в папке проекта выполнить `npm start` (production-сборка уже создана).

1. Проверить контейнер на машине с установленным Docker: `cp .env.example .env`, `docker compose up --build`. На этом Mac Docker не установлен, контейнер не запускался. Проверить /health и сохранение поездки после down/up с тем же volume.
2. Для деплоя выбрать Node/Docker-хостинг с постоянным диском и одним экземпляром приложения. Задать APP_BASE_URL и COOKIE_SECURE=true при HTTPS. Stateless/serverless-хостинг без постоянного диска не сохраняет JSON-поездки; для него сначала нужен адаптер TripRepository к БД.
3. Передать схему/доступ к каталогу команды и контракт реального агента. Подключение описано в data-integration.md. Нынешние цены, отзывы и геометрия остаются демо.
4. Для финального требования трека подключить настоящее вычисление хотя бы одной геохарактеристики. Отдельная геоистория в прототипе демонстрирует эффект знания, но не является живым георасчётом.
5. Подключить выданный команде GitHub-репозиторий, записать и опубликовать скринкаст, добавить публичную ссылку в README и проверить её в инкогнито. Тег submission поставить только на финальный коммит основной ветки.

Платные ключи для текущего локального демо не нужны. В проект включены локальные фотографии, шрифт, fixtures, расшифровка голосовых, Docker-файлы, документация и проверки.
