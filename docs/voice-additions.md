# Уточнения из голосовых

Источник: три файла от 26 октября, локальная расшифровка в voice-transcripts.md. В распознавании есть ошибки; названия сторонних приложений и неясные слова не считаются требованиями.

- Вход в подбор: крупное персональное приветствие и вопрос о поездке. Имя запрашивается при создании, затем используется в контексте.
- Карточка сценария: крупное фото атмосферы и компактные подписи занятия/плана. Уточнения агента приводят к выбору сценария.
- Стилистика следующих страниц должна продолжать первую. Общие токены и компоненты определяются до экранов.
- Приглашение по ссылке, отдельное пространство поездки после выбора. Это уже есть в письменном ТЗ, включая доступ приглашённых после принятого решения.
- Голосовой ввод назван возможной альтернативой тексту, не обязательной функцией. В прототипе основной ввод текстовый; микрофон без работающего распознавания не показывается.

Новых обязательных продуктовых шагов, противоречащих ТЗ, в голосовых не обнаружено. Разработка ведётся по письменному пути: состав поездки -> пожелания -> сценарии -> отели -> подтверждение -> пространство поездки.
