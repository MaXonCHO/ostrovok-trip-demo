# Дизайн

Светлый туристический продукт с сильной фотографией и спокойными рабочими поверхностями. Desktop является приложением с контекстной боковой панелью, мобильный интерфейс последовательный.

Источник палитры: раздел 12 ТЗ. Основной синий #0E41D2, hover #0636C8, active #0017B0; бирюзовый #32D6C5, мягкий #E0F8F4, текст #075E58. Текст #2D3137, вторичный #626873. Белые поверхности и фон #F4F6FA. Проектная тёмная тема через семантические токены.

Шрифт Golos Text, локальный OFL. Заголовки 28-40px, входной 48px; текст 16/24. Фото и карточки 20px, кнопки 12px. Компоненты и Phosphor icons едины. CSS и Motion, короткое движение только для изменения состояния. Референсы используются для композиции и приоритета фото.
