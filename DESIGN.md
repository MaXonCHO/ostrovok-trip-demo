# Сохранённый дизайн Островка

Используется текущая светлая система сайта. Шрифты Ostrovok PT для интерфейса, Ostrovok Spoof для крупных заголовков. Источник токенов: src/styles/ostrovok.css, типографика: ostrovok-type.css.

Новые страницы используют ov-container, существующие ov-button/ov-modal, шапку StorefrontShell и StorefrontFooter. Основной акцент синий, фон белый, вспомогательные поверхности светлые. Не создаём параллельный бренд, тёмную тему или новые шрифты.

Профиль: спокойная двухколоночная композиция на широком экране, одна колонка на телефоне. Общий контекст поездки отдельно от обсуждений конкретного отеля. На карточке: название, настоящее фото при наличии, краткие причины, требующие проверки условия, раскрываемые источники. Отсутствие фото является честным состоянием.

Действия входа, сохранения, приглашения, голосования и закрепления имеют loading/error/disabled-состояния. Поля с видимыми подписями. Мобильные цели от 44 px. Клавиатура и Escape работают в диалогах. Динамическая подборка объявляет изменения через aria-live. Движение только для обратной связи, учитывается reduced-motion.
