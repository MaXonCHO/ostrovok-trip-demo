Открыть index.html для визуального обзора.

цвета/       — HEX/RGB, CSS, JSON и SVG-палитра.
шрифты/      — сведения о Spoof Medium и Nagel Medium, ссылки,
               Golos Text с OFL как отдельная альтернатива для прототипа.
изображения/ — фотостиль, форматы и размеры; CSV с параметрами оригиналов.
референсы/   — 6 оригинальных иллюстраций кейса и источники с SHA-256.

Это собранная справочная папка, не официальный полный брендбук.
Названия цветов и шрифтов подтверждены кейсом. Числовая палитра измерена
по PNG; экспортные пресеты предложены для проекта. Брендовые шрифтовые
файлы и исходный вектор логотипа в комплект публичного кейса не входят.
Референсы — материалы The Clients / Островка, сохранены для изучения стиля.
